# iOS

- اللغة: Swift
- الواجهة: SwiftUI
- البلوتوث: `CoreBluetooth` (`CBCentralManager` + `CBPeripheralManager`)
- التشفير: swift-sodium
- Min iOS: 16

## متطلبات الـ IPA

- حساب Apple Developer (99$ سنوياً) للتوزيع عبر TestFlight
- ملاحظة: في الخلفية يقيّد iOS الإعلان عن الخدمة، فاختبر ذلك مبكراً.
