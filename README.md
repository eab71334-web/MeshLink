# MeshLink 📡

تطبيق محادثة **بدون إنترنت وبدون شبكة جوال**، يعتمد على بلوتوث (BLE) بنظام **Mesh**:
كل هاتف يعمل كعقدة تستقبل الرسالة وتعيد إرسالها للهواتف القريبة، حتى تصل للشخص المقصود
مهما كان بعيداً.

## الفكرة
```
هاتف A  ──►  هاتف B  ──►  هاتف C  ──►  هاتف D (المستقبل)
```
المسافة الكلية = عدد الهواتف في الطريق × مدى البلوتوث (30–100 متر لكل قفزة).

## المنصات
| المنصة | المجلد | المخرج |
|---|---|---|
| Android | `android/` | `.apk` |
| iOS | `ios/` | `.ipa` |

التطبيقان يتفقان على نفس البروتوكول الموصوف في [`docs/PROTOCOL.md`](docs/PROTOCOL.md)
ليتواصل أندرويد مع آيفون مباشرة.

## المميزات المخططة
- مراسلة نصية بين الأجهزة القريبة
- إعادة توجيه الرسائل عبر الهواتف (Multi-hop)
- حفظ وإرسال لاحقاً (Store-and-Forward)
- تشفير من طرف لطرف
- دعم أجهزة LoRa لمسافات بالكيلومترات (مرحلة لاحقة)

## الحدود المعروفة
- بدون هواتف كافية في الطريق لن تصل الرسالة.
- iOS يقيّد البلوتوث في الخلفية.
- Google Nearby Connections لا يعمل على iOS، لذلك نستخدم BLE الخام.
