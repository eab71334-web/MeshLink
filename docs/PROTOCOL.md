# بروتوكول MeshLink v0.2

> v0.2 غير متوافق مع v0.1: لازم تحدّث كل الأجهزة.

## 1. طبقة BLE
- كل جهاز: **Peripheral** (يعلن) + **Central** (يبحث ويتصل) معاً.
- Service UUID: `6E4D4C01-0000-1000-8000-00805F9B34FB`
- Characteristic: `6E4D4C02-0000-1000-8000-00805F9B34FB` (Write / WriteNoResponse / Notify)
- الإرسال للجار الذي اتصلنا به: **Write**. للجار الذي اتصل بنا: **Notify** (يشترك عبر CCCD).
- أقصى حجم للرسالة: **180 بايت**.

## 2. الرسالة (Packet) — ترويسة 45 بايت
| الحقل | الحجم | الوصف |
|---|---|---|
| version | 1 | 0x01 |
| type | 1 | 0=عامة، 1=ACK، 2=Announce، 3=خاصة |
| ttl | 1 | القفزات المتبقية (الافتراضي 7) |
| msg_id | 16 | معرّف فريد عشوائي |
| sender_id | 8 | أول 8 بايت من المفتاح العام للمرسل |
| recipient_id | 8 | المستقبل، أو `FF..FF` للبث |
| timestamp | 8 | ms (big-endian) |
| payload_len | 2 | big-endian |
| payload | متغير | حسب النوع |

## 3. أنواع الرسائل
- **0 عامة:** `[nickLen:1][nick][text]` — غير مشفرة، للبث.
- **2 Announce:** `[nickLen:1][nick][publicKey:32]` — يُبث كل 25 ثانية وعند كل اتصال جديد. يُتحقق أن `sender_id == publicKey[0..8]`.
- **3 خاصة:** `payload = nonce(12) ‖ ciphertext ‖ tag(16)`، و`recipient_id` = معرّف المستقبل.
- **1 ACK:** `payload = msg_id` للرسالة الخاصة المستلمة، و`recipient_id` = مرسل الرسالة الأصلية.

## 4. التشفير (للرسائل الخاصة)
1. تبادل المفاتيح: **X25519** بين المفتاح الخاص لك والعام للطرف الآخر (من Announce).
2. اشتقاق المفتاح: **HKDF-SHA256**، `salt = "MeshLink-v1"`، `info = "MeshLink private message"`، طول 32 بايت.
3. التشفير: **ChaCha20-Poly1305**، nonce عشوائي 12 بايت لكل رسالة، `AAD = sender_id ‖ recipient_id`.
4. الأجهزة الوسيطة ترى الترويسة فقط.

## 5. التوجيه (Flooding)
1. `msg_id` موجود في الذاكرة؟ تجاهل.
2. سجّله كمشاهَد.
3. إن كانت لي: عالجها (وأرسل ACK للخاصة).
4. إن `ttl > 0` وليست موجّهة لي: أنقص `ttl` وأعد إرسالها لكل الجيران.

## 6. Store-and-Forward
- كل جهاز يحتفظ بآخر **150** رسالة (عامة/خاصة) لمدة **6 ساعات** (ويحفظها على القرص).
- عند اتصال جار جديد تُرسل له كل الرسائل المحفوظة (التكرار يُتجاهل بـ `msg_id`).
- عند استلام ACK تُحذف الرسالة من المخزن.
