# بروتوكول MeshLink v0.1

## 1. طبقة BLE
- كل جهاز يعمل كـ **Peripheral** (يعلن عن نفسه) و**Central** (يبحث ويتصل) في نفس الوقت.
- Service UUID موحد: `6E4D4C01-0000-1000-8000-00805F9B34FB` (يُغيَّر لاحقاً)
- Characteristic واحد للكتابة/الإشعار: `6E4D4C02-0000-1000-8000-00805F9B34FB`
- الرسائل الأكبر من MTU تُقسَّم لشرائح (fragmentation) وتُجمَّع عند المستقبل.

## 2. شكل الرسالة (Packet)
| الحقل | الحجم | الوصف |
|---|---|---|
| version | 1 byte | رقم الإصدار (0x01) |
| type | 1 byte | 0=نص، 1=ACK، 2=Announce |
| ttl | 1 byte | عدد القفزات المتبقية (الافتراضي 7) |
| msg_id | 16 bytes | معرّف فريد (UUID) |
| sender_id | 8 bytes | أول 8 بايت من المفتاح العام |
| recipient_id | 8 bytes | المستقبل (أو 0xFF..FF للبث العام) |
| timestamp | 8 bytes | بالملي ثانية |
| payload_len | 2 bytes | طول المحتوى |
| payload | متغير | محتوى مشفر |

## 3. التوجيه (Flooding)
1. استلام رسالة → إن كان `msg_id` موجوداً في الذاكرة: تجاهلها.
2. احفظ `msg_id` (لمدة 10 دقائق مثلاً).
3. إن كنت أنا المستقبل: فك التشفير واعرضها.
4. وإلا إن `ttl > 0`: أنقص `ttl` بواحد وأعد إرسالها لكل الجيران ما عدا مصدرها.
5. إن لا يوجد جيران: خزّنها وأرسلها عند ظهور جار جديد (Store-and-Forward).

## 4. التشفير
- تبادل المفاتيح: X25519
- تشفير الرسائل: ChaCha20-Poly1305 (libsodium)
- كل جهاز يولّد زوج مفاتيح عند أول تشغيل ويخزّنه في Keystore (Android) / Keychain (iOS).
- الهواتف الوسيطة ترى الترويسة فقط ولا تقرأ المحتوى.
